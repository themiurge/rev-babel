# apps/web/templates

Server-rendered page templates for the avatar picker, Eco captions, and
Play.

User-facing strings are Italian, English, French, and Arabic, including
right-to-left layout for Arabic (see `docs/overview.md`).

- `games/*.html` are full-window pages, one per lesson tutorial or game
  (including lesson 8's take-home card, `games/scheda_social.html`, a
  printable A4 landscape page).
- `present.html`, `present_remote.html` and `materials.html` are
  capture-host only (the teacher's projector, phone remote and materials
  page).
