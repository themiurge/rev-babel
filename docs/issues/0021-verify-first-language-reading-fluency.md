# 0021. Verify first-language reading fluency

- **Status:** blocked
- **Owner:** 🧑 Emilio
- **Milestone:** —
- **Opened:** 2026-09-05

## Context

Unverified for every user, in any language. If captions cannot be read,
Eco's central design assumption changes. Blocked until lesson 1.

## What it takes

Observe whether the captions are actually being read. Keep the caption
page simple enough that a change of direction — larger type, fewer lines,
one language at a time — is a CSS change rather than a rewrite.

## Done when

An honest answer recorded in `open-questions.md`, and any consequent design change filed as its own issue.
