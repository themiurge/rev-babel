# 0011. Settle the speaker gate

- **Status:** open
- **Owner:** 💻 code
- **Milestone:** M2
- **Opened:** 2026-09-05

## Context

[`eco.md`](../eco.md) leaves the mechanism open.
[`data-and-privacy.md`](../data-and-privacy.md) requires incidental student
audio to be discarded — a single-source gate satisfies that only as well as
the microphone's pickup pattern does (issue 0003).

## What it takes

For lesson 1 the honest answer is the cheap one: the lavalier is the only
audio source, so the microphone *is* the gate. Record it as a decision, and
revisit if the room turns out to be audible.

## Done when

A decision record, and a test recording showing what a voice from across the room actually contributes.
