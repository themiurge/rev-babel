# 0006. The invented classroom corpus

- **Status:** open
- **Owner:** 💻 code
- **Milestone:** M1
- **Opened:** 2026-09-05

## Context

The highest-value artefact in milestone 1. Real lesson transcripts can
never be used ([`data-and-privacy.md`](../data-and-privacy.md)), and
public benchmarks look nothing like a computer-literacy lesson.

## What it takes

~60 invented sentences in the register of the course, of which ~15 mix
Italian and English the way the teacher actually speaks. Committed, because
invented. This is what every translation backend is measured against.

## Done when

The corpus exists with reference translations, and the eval harness scores against it.
